# Notebook provenance

`kaggle_provenance_notebook.ipynb` is the archived **base corrected experiment** notebook (saved Version 9). It contains exploratory, recovery, and audit cells in addition to final base-experiment cells.

The character-baseline and fuzzy/near-duplicate sensitivity extensions were executed after that archived base state. Their canonical scripts and machine-readable summaries are included in this release; see `docs/PROVENANCE.md`.

For reproducibility, use `sqlshield/pipeline.py` and `scripts/` rather than copying arbitrary notebook cells.
